Private repo / Python / ModernGL / GLSL

audiovisual

A real-time generative visual engine driven by live audio. It captures audio, extracts features like RMS, FFT magnitude, spectral centroid, frequency bands, onset, and kick-like transients, then maps them to shader parameters for ModernGL visuals. The project also includes text and Tkinter preview renderers, configs, docs, tests, linting, typing, and CI.
