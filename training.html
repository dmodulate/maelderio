Course Snippet

Code/C++14-17/C++17TemplateFeatures/20_FoldExpressions.md

Fold expressions collapse parameter packs with an operator. They are one of the cleanest C++17 additions for variadic templates.

(... + values) = v1 + v2 + ... + vn

template<typename... Args>
auto sum(Args... args)
{
    return (... + args);
}

Course Snippet

Code/C++Research/C++20/concepts.md

Concepts make template requirements explicit. They improve diagnostics and turn informal template assumptions into named constraints.

Concept = compile-time predicate over T

template<typename T>
concept Number = std::integral<T> || std::floating_point<T>;

template<Number T>
T square(T value) { return value * value; }
